# Changelog

## 0.1.0

- First release. Send requests from .http and .rest files with a Send Request link or Ctrl+Alt+R (Cmd+Alt+R on macOS).
- Response viewer beside the file: status, time, size, a JSON tree, pretty and raw views, XML, images, headers, cookies, a timing breakdown and the request as sent.
- File variables, environments from http-client.env.json or settings, built-in values ($guid, $timestamp, $randomInt, $datetime, $processEnv, $dotenv) and chained requests with # @name.
- Paste a cURL command as a request and copy any request as cURL. Request history, kept as written.
- Zovo Pro tools with 3 free tries each: import API collection exports and OpenAPI files, run all requests with assertions (JUnit XML and HTML report), and generate code in 8 languages.
